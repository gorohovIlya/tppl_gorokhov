# Выбор парадигм программирования и языков

## 1. Обработка больших данных в реальном времени

**Парадигма:** Императивная 
**Язык:** Rust

Императивная парадигма позволяет эффективно управлять последовательностью операций, состоянием системы, памятью и параллельными потоками обработки данных.

Rust выбран, поскольку он сочетает высокую производительность с безопасным управлением памятью и поддержкой многопоточности. Это особенно важно для обработки большого потока изображений в реальном времени и обеспечения непрерывной работы системы 24/7. Также в Rust есть необходимые инструменты для решения данной задачи — библиотеки `image`, `rayon`, `ndarray` и др. — и возможность использовать CUDA через библиотеки, например `cudarc`.

## 2. Прототип ML-сервиса для прогноза погодных условий

**Парадигма:** Функциональная, декларативная
**Язык:** Python

Функциональная парадигма здесь предпочтительна, поскольку ML-задачу удобно представить как последовательность преобразований, а каждый из этих этапов — как функцию. Декларативная парадигма также применима здесь в связке с PyTorch и TensorFlow из-за того, что эти библиотеки предлагают возможность собирать модели из готовых слоёв.

Python хорошо подходит для этой задачи, поскольку обладает интуитивным синтаксисом и предоставляет доступ к готовым библиотекам, например NumPy, Pandas и, в особенности, scikit-learn, PyTorch и TensoFlow.

## 3. Интерактивный UI для торгового терминала

**Парадигма:** Реактивная
**Язык:** TypeScript

Реактивная парадигма хорошо подходит для работы с фронтенд-частью веб-приложений, т.к. описывает как реагировать на изменения, а не что получить.

TypeScript выбран, поскольку фронтенд является одной из основных сфер его применения. Кроме того, TypeScript обладает статической типизацией и позволяет отделить бизнес-логику от UI, что положительно влияет на тестируемость. Также TypeScript позволяет использовать frontend-фреймворки Vue, React и Angular, что может ускорить разработку.

## 4. Прошивка для устройства регистрации температуры

**Парадигма:** Императивная
**Язык:** C

Императивная парадигма хорошо подходит для разработки прошивки, поскольку позволяет напрямую управлять аппаратными ресурсами микроконтроллера, контролировать последовательность операций и обеспечивать предсказуемое время выполнения.

C выбран благодаря низким накладным расходам, возможности напрямую работать с регистрами GPIO, ADC и UART, а также поддержке низкоуровневого управления памятью и энергопотреблением. Кроме того, C широко используется для разработки прошивок и поддерживается большим количеством микроконтроллеров, что упрощает перенос кода между различными платформами.
