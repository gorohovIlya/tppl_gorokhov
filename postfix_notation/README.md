# Postfix Notation Stack Machine
Python-реализация Стек-машины для вычисления выражения, записанного в постфиксной нотации

## Установка
```bash
python install -e .
```

## Использование

```bash
python main.py "2 3 +"

# Результат
# Шаг: 1. Стек: [2.0]
# Шаг: 2. Стек: [2.0, 3.0]
# Шаг: 3. Стек: [5.0]

# Выражение = 5.0
```

Допускается вариант запуска программы с выражением без кавычек
**ВНИМАНИЕ** При запуске программы с выражением без кавычек используйте экранирование для символов операций 
**УМНОЖЕНИЕ** **( * )** и **ТИЛЬДА** **( ~ )**

Пример правильного ввода:
```bash
python main.py 2 3 \*

# Выведет:
# Шаг: 1. Стек: [2.0]
# Шаг: 2. Стек: [2.0, 3.0]
# Шаг: 3. Стек: [6.0]

# 2 3 * = 6.0
```

Пример **НЕПРАВИЛЬНОГО** ввода:
```bash
python main.py 2 3 *

# Выведет:
#Ошибка. Некорректный элемент в выражении: `main.py`
```
